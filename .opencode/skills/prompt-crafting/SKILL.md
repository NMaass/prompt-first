# Writing Effective Prompts

When you're asking the AI builder to create or change something, the quality of your description directly affects the quality of what gets built. Here's how to write prompts that get great results.

## The Five Parts of a Good Prompt

### 1. Who is this for?
Tell the builder who will use this product. Different users need different things.

**Weak:** "Make a tracker app"
**Strong:** "Make a habit tracker for college students who are busy with classes and want to build better daily routines"

### 2. What should it do?
Describe the main things users should be able to do. Be specific about actions.

**Weak:** "It should track habits"
**Strong:** "Users should be able to add custom habits, check them off each day, and see how many days in a row they've completed each habit"

### 3. How should it feel?
Describe the mood, style, or personality of the product.

**Weak:** "Make it look nice"
**Strong:** "It should feel calm and encouraging — not overwhelming. Use soft colors and simple layouts"

### 4. What matters most?
If you had to pick one thing that must work perfectly, what is it?

**Weak:** (nothing mentioned)
**Strong:** "The most important thing is that checking off a habit feels satisfying and the streak count is always visible"

### 5. What should it NOT do?
Setting boundaries helps the builder focus.

**Weak:** (nothing mentioned)
**Strong:** "Don't add social features or sharing. This is a personal tool."

## Common Prompt Mistakes

- **Too vague:** "Make it better" → Better: "The add button is hard to find on mobile — make it more prominent"
- **Too technical:** "Add a REST API endpoint" → Better: "Let users save their data so it's there when they come back"
- **Too many things at once:** List 10 features → Better: Start with the 2-3 most important features
- **Describing solutions instead of problems:** "Move the button to the top right" → Better: "I keep missing the main action — it's not obvious enough"

## Template

Try this format for your first prompt:

"Build a [type of app] for [who]. They need to [main actions]. It should feel [mood/style]. The most important feature is [priority]. Don't include [exclusions]."
