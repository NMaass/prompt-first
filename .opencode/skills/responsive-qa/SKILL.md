# Responsive QA

Use the current preview URL. Run `studio-browser-check` with `responsive` for the relevant requirement.

Inspect failures rather than merely checking viewport screenshots. Important controls must remain reachable, text must not require horizontal scrolling, and the primary journey must stay understandable at each size.

Fix product code when needed, rerun the check, and keep failed evidence visible until a later receipt proves the requirement.
