# Accessibility QA

Run both `accessibility` and `keyboard` browser checks for the primary journey.

Treat automated checks as a baseline, not proof of full WCAG conformance. Repair missing names, labels, document metadata, focus failures, and obvious semantic problems. Where a requirement still needs human judgment, publish it as unverified rather than implying automated coverage is complete.
